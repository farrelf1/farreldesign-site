# farreldesign-site

Portfolio of Tubagus Farrel Fadillah, multimedia designer.

- `index.html`, `css/styles.css`, `js/app.js` are what GitHub Pages serves.
- Edit `src/app.js` and `css/src.css`; `js/app.js` and `css/styles.css` are built from them (esbuild bundle with GSAP and Lenis; Figtree is inlined into the CSS).
- Live counter, cursors and Clarity stats: fill in `js/live-config.js`.
