# Farrel Fadillah · rounded portfolio

A single page in plain HTML, CSS and JS. No build step, no libraries: open `index.html`.

- `js/work-data.js` holds the projects. Add images to `images/<id>/` and list them there.
- `css/styles.css` has the colours and springs at the top (`:root`).
- `js/app.js` runs the motion: hero letters, the colour fields (a tiny canvas scaled up),
  the sliding nav highlight, scroll reveals, the work cards, the project sheet and
  the copy-email confetti. Everything respects "reduce motion".

Inspired by the warm gradient and numbered sections of the Redo guideline site, with
rounder shapes and more play. Font: Red Hat Display (SIL OFL, see `fonts/OFL.txt`).
